<h1 align="center">Agentix</h1>

**Agentix** is an open-source SDK that lets AI agents _think_ and _transact_ across every chain.

- 🔗 **All chains, one kit** – plug-and-play wallets, plugins, and on-chain tools  
- 🤖 **Agent-ready** – simple, typed APIs your LLM/rag pipeline can call immediately  
- ⚡ **Node.js + pnpm** – zero-config monorepo workflow  
- 🛠️ **Status** – `alpha` • expect rapid iteration
